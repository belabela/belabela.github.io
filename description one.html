Project #1

Order Classification Using Conditional Logic (Excel Project)

In this project, I developed a conditional logic system to automatically identify and classify special customer orders based on predefined criteria. The goal was to improve efficiency in reviewing large volumes of order data. Using Excel formulas, I created a rule that checks two key conditions:

  • Whether the quantity of any single fruit exceeds 10 pieces
  • Whether the total number of fruits in an order exceeds 20 pieces

If either condition is met, the order is labeled as Special Order; otherwise, it is marked as No.

This project demonstrates my ability to:

  • Apply logical functions (such as IF, OR)
  • Analyze and structure data effectively
  • Build automated decision-making systems in spreadsheets
  • Ensure accuracy and consistency in data classification

Project #2

Statistics Analysis of Fruit Orders (Excel Project)

In this project, I performed a descriptive statistical analysis on a dataset of fruit orders to better understand ordering patterns and data distribution. Using Excel functions, I calculated key summary metrics, including:

  • Total Orders: 104
  • Maximum Order Size: 26 fruits
  • Minimum Order Size: 7 fruits
  • Median Order Size: 18.5 fruits
  • Average (Mean): 17.33 fruits
  • Standard Deviation: 8.21

These calculations provided valuable insights into customer ordering behavior, such as the typical order size, variability between orders, and the overall spread of the data.

Through this project, I demonstrated my ability to:

  • statistical functions (SUM, AVERAGE, MEDIAN, MAX, MIN, STDEV)
  • Interpret numerical data to extract meaningful insights
  • Summarize datasets into clear and actionable information
  • Ensure accuracy and consistency in data analysis

This type of analysis helps businesses make data-driven decisions, such as inventory planning, demand forecasting, and identifying unusual order patterns.

Project #3

Automatic Data Comparison Solution in Excel

I created an Excel solution that automatically compares two values and gives a clear result for each row.

What the solution does:

Checks if the value in Column B is greater than Column C If true → shows Apples Rule If not → shows False

Formula used: =IF(B2>C2, Apples Rule, False)

What you get from this solution:

  • No need to manually compare data
  • Instant and consistent results
  • Faster data review process
  • Reduced human error
This type of solution is useful for any task where you need to quickly compare values and make decisions based on the result.
